# 真实小店试水执行清单

> 目标：用最少的商家、最短的时间拿到真信号。**3 个商家试用 ≥1 周、≥1 个愿意付首月费（$49–99 档）→ 继续；否则砍掉或换切口。**
> 红线：不擅自联系任何商家。每个商家都要先有 Dai 提供网址或批准、且商家本人确认授权抓取，才开始。
> 配套材料：演示与话术见 `01-demo-and-outreach.md`。

---

## 阶段 0 · 选店与授权（联系前）

第一批候选画像（2026-11-02 已定的方向）：客服问题棘手的小独立站，不碰 Amazon / Etsy 大平台店。优先顺序待 Dai 最终点选品类后按此表筛：

- [ ] 独立站（有自己的域名和产品 / FAQ / 物流 / 退换页，不是只有平台店铺页）

## 阶段 2 · 20 题命中测试（开通当天完成）

## 阶段 4 · 付费信号判定（一周结束当天谈，只记原话）

谈法：先一起看阶段 3 的汇总数，再问一句：「这个结果，按 $___ / 月（在他档位内报一个数：$49 / $79 / $99）续一个月，你续吗？」问完停，不推销、不降价换点头。

| 信号等级 | 判定标准（以行为为准，不以客气话为准） | 本商家是否出现（Y/N + 证据） |
|---|---|---|
| 强：付费 | 当场愿意付首月费 / 已付款 / 主动问怎么付款 |  |
| 强：续用 | 主动问试用后怎么继续、能否长期挂着 |  |
| 中：投入 | 试用期内补了 FAQ、改了政策页、主动给未答题补答案 |  |
| 中：习惯 | 多次主动看未答列表，把它当工作清单用 |  |
| 弱：客气 | 只说「挺好 / 挺有意思」，不谈钱也不投入 |  |
| 负：拒绝 | 明确说不需要 / 价格不值 / 宁可自己回 |  |
