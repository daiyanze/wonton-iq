## 推荐顺序

### 1. 雑貨屋さんitou（首选，日本 · BASE · 杂货）

- 店铺页（FAQ 已核验 live）：https://itou.shopselect.net/p/00001
- 为什么排第一：日本店（Dai 的主场：日语 + 时区 + 导入支援预期），BASE 店正好是日本简报建议的第一批池子（BASE / STORES / Shopify 日本店）；FAQ 内容最全，20 题好出：物流有分地区运费表（北海道 ¥1000 / 东北 ¥1200 / 关东～四国 ¥1400 / 九州·冲绳 ¥1500，¥8000 以上免邮，付款后 5 日内发货）、礼品包装 +¥300（定制/礼品类题有料）、退换规则明确（原则不接受，仅不良品 1 周内对应）——物流/退换/礼品三类题都能覆盖，缺口题也容易找（比如能否指定配送日期、能否合并发货）。
- 联系方式：站内导航有 CONTACT（BASE 站内咨询表），另有特定商取引法表記页。
- 注意：BASE 子域名店（itou.shopselect.net），不是自有域名；清单阶段 0 偏好自有域名，这里按日本简报的口径放宽了，Dai 点头即算认可。

### 2. med（日本 · BASE · 手工染色服饰杂货）

- 购物指南页（已核验 live）：https://med202306.base.shop/p/00002
- 为什么排第二：同样日本 BASE 小店；产品使用类题材最有特色——茶染会褪色、洗后退色不补染、穿后修理可能收费，这些都是“产品使用/保养”类好题；物流（1 周左右发货，ゆうパック全国 ¥1200，¥20000 以上免邮）、退换（顾客原因不接受，不良品 Instagram DM 联系）都齐全。
- 联系方式：Instagram DM（政策页原文写明不良品请 Instagram DM 联系）。
- 注意：同为 BASE 子域名；联系渠道是 Instagram DM，不是邮箱/表单，首次联系话术要按 DM 改一版（清单里的 5 条话术是邮件/表单口径）。

### 3. Color Wheel Crafts（英文备选 · 自有域名 · 一人手工首饰，美国阿拉斯加）

- FAQ 页（已核验 live）：https://www.colorwheelcrafts.com/faqs.htm
- 为什么是英文首选：自有域名，完全符合清单阶段 0 画像；FAQ 最丰富，20 题覆盖最全：退换（全场 final sale，破损 7 天内联系）、支付（PayPal）、物流（美国境内 2–5 天、国际 2–12 周，在库商品 1–3 个工作日发货）、丢件（Priority 保险 $50）、产品保养（按金属种类分 5 条护理说明）、过敏/窒息安全提示；站内有 Contact 页可发邮件。
- 注意：英文店、美国店主，时差大；如果 Dai 想先打日本市场，这家只作英文线备选。

### 4. Made of Dust Ceramics（英文备选 · 自有域名 · 陶艺工作室，塞尔维亚）

- 政策页（已核验 live）：https://www.madeofdustceramics.com/pages/payments-shipping-returns
- 为什么入选：自有域名的小工作室；政策 + FAQ 极全：自提/配送、三种付款方式、10 天退换、破损 24 小时内拍照发邮件、国际配送 10–15 天、定制（20 件以上批发定制才接）、礼品包装；公开邮箱 info@madeofdustceramics.com，联系路径最直接。
- 注意：塞尔维亚店，英文沟通；定制类题材是批发定制不是个人定制，出题时别搞混。
