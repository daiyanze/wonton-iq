# 预注册 — 第四轮校准实验（S5b 混合管线的 JEV 接受线：0.8 / 0.9 / 0.95）

> 日期：2026-11-14（本文件写于 v4 新题编写与任何第四轮模型调用之前；文件顺序：本预注册 → `questions-v4-additions.json` → `run_s5cal.py`，三者按此顺序落盘，便于事后核对没有看题后改规则。）
> 纪律同第一、二、三轮（`README.md`、`prereg-round2.md`、`prereg-round3.md`）：规则先写死，跑完照此判定，不改口径。Dai 已批准本轮。

## 背景与目的

第三轮的结论是：稠密腿（本地 BGE-M3）有效性被完全坐实——S5b 在 v3 弱点题库 48/50、池召回三组全 1.00、回归 95/100、编造 0；但**新题库回退正确率 10/12 = 83.3%，差 1 题没过预注册的 90% 线，S5b 未被采纳**，生产保持 S2-cal（BM25 + JEV@0.8）。

唯一卡点是 JEV 门在近失陷阱上的误收：v3 新题库仅有的 2 道漏检是同一陷阱的中文/日文版（“下单后改配送地址”），配送 chunk 被以 noul **0.90（中文 V3Z15）/ 0.89（日文 V3J08）**接受，恰在 0.8 线上方；而 v3 答题命中里只有 3 道的最高 noul 落在 [0.80, 0.95)。**候选线 0.9 / 0.95 的来源在此如实登记：它们是回看第三轮已记录的误收分数（0.89–0.90）与答题分数分布挑出来的，与第二轮的 0.8 来自第一轮敏感性诊断是同一种“诊断提假设、新轮新题验真伪”的关系——本轮数字本身不构成采用证据，v4 新题不过线，这个诊断就当作过拟合处理。**

本轮只验证一件事：**管线其余全部不动，只把 S5b 的 JEV 接受线从 0.8 抬到 0.9 或 0.95，能否在从未见过的陷阱加权新题上把回退正确率清过 90%，同时不误伤答题。**

## 唯一变量（本文件写下后冻结）

只动**接受线**一处：noul 接受阈值 ∈ {0.8（对照，即第三轮/生产口径）、0.9、0.95}。

管线与第三轮 S5b **逐项一致**，不许有任何其他改动：

- 候选池 = BM25 全部命中块 ∪ 稠密 top-8（本地 BGE-M3，`BAAI/bge-m3` @ HF 修订 5617a9f6，sentence-transformers，L2 归一化余弦），按 chunk id 去重；
- 接受块的拼答顺序按 RRF（k=60）融合 BM25 表与稠密 top-8 表，同分定序规则同第三轮；
- JEV 门与第三轮/生产**逐字一致**：同一 Noul instructions / criteria（`run_s2.py` 常量）、每题全部候选打包一次请求、请求别名 `jev-latest`；
- 拼答（原文拼接 + 出处去重）与兜底行为不变；本地嵌入环境同第三轮（venv `eval/.venv-emb`，运行一律 `HF_HUB_OFFLINE=1`，详见 `round3-setup.md`）。

**明确不在本轮**：BM25 trigram 分词补丁、JEV 提示词改动、动作意图层、候选池构造改动——一次只变一个变量。

## 方法（本文件写下后冻结）

- **一次运行、三线同判**（第二轮先例）：管线在 v4 题库上只跑**一次**，逐题记录每个候选块的 noul 概率；0.8 / 0.9 / 0.95 三条线全部从同一批记录概率离线判分。0.8 线的判分结果同时充当本轮对照，并应与“第三轮口径”自洽（同管线、同线）。
- **第三轮已记录概率复判（标注为回归/诊断，不进主裁决）**：用 `results/s5b-local-bge-m3.json` 里已记录的逐块概率与候选池顺序，把 v3 新题集 50 题与 v1+v2 回归集 100 题按 0.9 / 0.95 两条线离线重判（概率复用的可信度已在第二轮验证过：0.5 线重判与第一轮逐题判定 0 处不一致）。这一项进 ADOPT 规则 (d)，但与 v4 主裁决分开报告，永不合并计分。
- 评分口径与前三轮逐字一致：复用 `run_s2.verdict_for`（hit = 行为对 + 来源命中 + 期望事实 ≥ 一半；兜底/转人工组行为对了即 hit，返回答案文本即 miss）。
- 延迟/成本口径：接受线只改变“哪些已打分的块被拼进答案”，不产生额外调用，**延迟与成本与第三轮 S5b 相同、不随线变化**，成绩单只记录本轮实测的单次运行延迟/成本作存档，不设采用线。

## 题库 v4（规格在本文件写下后冻结，新题在预注册之后编写）

- 语料不变：冻结的 Momo Ceramics 5 页 / 10 个知识块，不许改。
- **新题 40 道，陷阱加权**（headline 集），全部针对同一批冻结英文页面；可答题的期望事实一律用页面里的英文事实串（同 v1 中文组、v3 的做法）：
  - **近失陷阱 ×20**（组 `trap4`，期望 fallback）：与真实 chunk 话题高度相邻、但被问的具体事实在 5 页中根本不存在——即第三轮的失败模式。语言分布约 EN 8 / ZH 7 / JA 5。其中包含“对订单做修改/取消/加急”家族的**新表述**（信息问法为主），但**不得复制 V3Z15 / V3J08 的原题**，且各题沉默的事实互不相同；
  - **无答案 ×8**（组 `unans4`，期望 fallback）：站内根本没有的事实，EN/ZH/JA 混合；
  - **转人工/动作请求 ×6**（组 `hand4`，期望 handoff）：EN/ZH/JA 混合，正确答案是转人工，声称已执行 = 编造类严重失败；
  - **可答对照 ×6**（组 `ans4`，期望 answer）：EN/ZH/JA 混合、正常难度——专门用来侦测接受线收得太紧时答题组的误伤。
- **v4 回退集** = 陷阱 20 + 无答案 8 + 转人工 6 = **34 题**（ADOPT 规则 (a) 的分母）；**v4 答题组** = 可答对照 6 题（规则 (b) 的口径）。
- 新题编写规则（同前三轮）：可答题的期望事实必须逐字能在期望来源页的知识块中找到，逐题程序核验；陷阱/无答案题的“缺失事实”必须在全部 5 页原文中检索确认不存在，逐题记录核验词；任何一道新题不得与 v1+v2+v3 任一题重复或轻微改写（英文按 token Jaccard、CJK 按字符 4-gram 筛查，报告最高相似度）；新题由 agent 在本预注册之后、任何第四轮模型调用之前编写（文件 `questions-v4-additions.json`；合并版 `questions-v4.json` 带 `set` 字段）。

## 决策规则（最终版，跑完照此判定）

**候选线 L ∈ {0.9, 0.95} 达标（ADOPT-eligible）——以下四条全部满足才算：**

- (a) **v4 回退正确率 ≥ 90%**：v4 回退集 34 题中，按线 L 判分的行为正确题数 ≥ 31（即 ≥90%，34 题口径下至少对 31 题）；
- (b) **v4 答题不误伤**：v4 可答对照 6 题按线 L 的命中数，相比同一批概率按 0.8 线的命中数，下降 ≤ 1 题；
- (c) **编造 = 0**：线 L 下 v4 全部回退组 miss 逐条人工复核，无编造事实、无声称已执行操作（编造为一票否决，同前三轮）；
- (d) **第三轮成绩复判不塌**：已记录概率按线 L 重判，v3 新题集总命中 ≥ 47/50，且 v1+v2 回归集总命中 ≥ 93/100。

**多线达标时的取舍（本文件写下后冻结）**：

- 0.9 与 0.95 都达标 → 采纳**较低的 0.9**（少牺牲召回）；
- 只有一条达标 → 采纳该线；
- 两条都不达标 → **混合路线不采纳，生产保持 S2-cal**；记录卡在哪条，并把**动作意图层**记为下一个杠杆（不再自行追加标定轮次）。

**ADOPT 的含义**：指“混合管线 + 接受线 L”通过本轮，**不等于授权改 `app.py`**——动生产仍需 Dai 另行点头（同第二轮规矩）。
