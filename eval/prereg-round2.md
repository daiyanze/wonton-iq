# 预注册 — 第二轮校准实验（JEV 接受线 0.8 + 扩充题库）

> 日期：2026-11-14（本文件写于新题编写与任何第二轮 JEV 调用之前；文件顺序：本预注册 → `questions-v2-additions.json` → `run_s2cal.py`，三者按此顺序落盘，便于事后核对没有看题后改规则。）
> 纪律同第一轮（`README.md`）：规则先写死，跑完照此判定，不改口径。

## 目的

第一轮的结论是：JEV 决策层是真增益（S2 总分 46/55 vs S0 24 / S1 26），但接受线 0.5 时兜底组 D+E 只有 11/14（79%），过不了预注册的 90% 采用线，所以没有采用任何带 JEV 的方案。

第二轮只验证一件事：**把接受线预先定死为 noul ≥ 0.8，能否在从未见过的新题上清过兜底线。** 0.8 这个数不是本轮看题定的，它来自第一轮的敏感性诊断，如实登记在下：

- 第一轮 S2 的逐块概率（`results/s2-jev-single.json`）呈双峰分布：正确块的 noul 基本 ≥0.95，D 组陷阱块落在 0.56–0.81（D01 0.79、D04 0.70、D07 0.56）。用第一轮已记录概率按 0.8–0.9 接受线离线重判，v1 总分 50/55、D+E 14/14。
- 该诊断只说明“差距像是标定问题，不是能力问题”；它不能算采用证据，因为 0.8 是回看第一轮数据挑的。本轮把它当作先验假设，在全新题上重验——新题不过线，第一轮的诊断就当作过拟合处理。

## 题库 v2（规格在本文件写下后冻结，新题在预注册之后编写）

- 语料不变：冻结的 Momo Ceramics 5 页，不许改。
- **新题 45 道（headline 集，全部英文核心组）**：A 直问 8、B 改写 8、C 多跳 8、D 近似陷阱 10、E 无答案 6、F 人工边界 5。权重向第一轮的弱项倾斜（D 组从 8 增至 10）。
- v1 的 55 道英文核心题只作**回归集**：用第一轮已记录的逐块概率（`results/s2-jev-single.json`）按 0.8 线离线重判，不做新调用，明确标注为复用数据；与新题分数**分开报告，永不合并**。
- 新题编写规则（同 v1 方法论）：可答题的期望事实必须逐字能在 5 页中找到，并登记期望来源页与期望事实串；D 题的“缺失事实”必须在全部 5 页中检索确认不存在；F 题正确答案一律是转人工；任何一道新题不得与 v1 任一题重复或轻微改写，东拼西凑的算术/组合题也要是新组合。
- 新题由 agent 在本预注册之后、任何第二轮 JEV 调用之前，依据冻结页面编写（文件 `questions-v2-additions.json`；合并版 `questions-v2.json` 带 `set` 字段）。

## 评分口径（与第一轮逐字一致）

- hit / partial / miss 三档，复用 `run_baseline.py` / `run_s1.py` / `run_s2.py` 共用的 `verdict_for` 逻辑：答题组看行为、来源命中、期望事实出现 ≥ 一半；兜底/转人工组行为对了即 hit，返回了答案文本即 miss。
- D/F 组全部 miss 由人工逐条复核：回答是原文逐字引用（无害引用）、编造事实（不存在的折扣码/参数/承诺）、还是声称已执行操作。复核结论写进成绩单。
- 延迟口径同第一轮：题目间 4 线程并行，每题延迟记“服务时间”= 本地 BM25 耗时 + 该题 JEV 调用耗时；采用线看新题集核心题的 p50。
- 成本口径同第一轮：input tokens 取响应 usage 实测，按官方价 $0.042/1M 计，output 免费；采用线看新题集每题平均成本。

## 决策规则（最终版，跑完照此判定）

**ADOPT（建议把 app.py 的决策层换成 JEV@0.8，仍需 Dai 最终点头才动 app.py）**——以下六条全部满足才触发：

1. 新题集兜底组 D+E 正确率 ≥ 90%；
2. 新题集总命中率 ≥ S1 在新题集的总命中率 + 15 个百分点（口径同第一轮规则的“高 ≥15 个点”）；
3. 编造 = 0（D/F 组人工复核无编造事实、无声称已执行操作）；
4. 新题集每题延迟 p50 ≤ 3 秒；
5. 新题集每题成本 ≤ $0.01；
6. v1 回归集在 0.8 线的总命中 ≥ 44/55（即不比第一轮 0.5 线的 46/55 掉超过 2 题，防新线在老题上大面积误杀）。

**未过线时的既定结论**：

- 若新题集 D+E < 90%：JEV 路线暂停。第二轮之后不再自行开第三轮标定（任何新的标定轮次需 Dai 另行决定）；建议回到用现版 BM25 app 找真实商家试水。
- 若 D+E 过线但其他某条不过：ADOPT 不触发，逐条记录卡在哪条，等 Dai 决定，不自行放宽。
- D/F 组出现任何一处编造：无论总分多少，ADOPT 一票否决。
