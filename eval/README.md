# 检索方案实验 — 题库与决策规则

> 目的只有一个：**用同一套题、同一套评分，决定客服 MVP 的检索层下一步走哪条路**——继续用现在的 TF-IDF、只升级到 BM25、还是上 SAG2（BM25 + JEV 决策模型）。规则先写死，跑完不许改判（和 triple-sigma 战绩台账一个纪律）。

## 语料（冻结）

虚构店 Momo Ceramics 的 5 个页面：`sample_store/{index,product,shipping,returns,faq}.html`。
实验期间不许改这 5 个页面；要改语料，先升题库版本。所有题目的期望答案都只来自这 5 页的原文。

## 对比的系统（一次只变一个变量）

| 代号 | 系统 | 变量 |
|---|---|---|

## 评分（自动 + 人工复核两层）

自动评分脚本 `run_baseline.py`（可改造成通用 runner）按题给三档：

- **hit**：行为对（该答的答、该兜底的兜底、该转人工的转人工）+ 来源页命中 + 期望事实在返回文本中出现 ≥ 一半；
- **partial**：行为对，但来源或事实缺一半以上；
- **miss**：行为错。其中答题组返回了兜底 = miss；兜底/人工组返回了答案文本 = miss 并标记待人工查是不是编造。

人工复核只看三类：D/F 组的 miss（判断是无害引用还是编造）、C 组的 partial（事实齐不齐）、以及任何声称已执行操作的输出（F 组，一票否决项）。

核心指标（英文 55 题）：总命中率、各组命中率、兜底组（D+E，14 题）正确率、人工组（F，5 题）正确率、编造次数、延迟 p50、每题成本。

## 决策规则（2026-11-14 预先定好，跑完照此执行）

1. **上 SAG2（S3）**：S3 总命中比 S0 高 ≥15 个点，且 C 组高 ≥30 个点，且 D+E 兜底正确率 ≥90%，且编造 = 0，且托管 JEV 延迟 p50 ≤3 秒、每题成本 ≤$0.01。
2. **只上 S2（单轮 JEV）**：S2 与 S3 总命中差 <5 个点（说明这家店的问题基本是单跳，多跳扩展不值复杂度），且 S2 满足规则 1 的兜底/编造/延迟/成本线。
3. **只换 BM25（S1）**：S1 与 S2/S3 中最好的那个差 <5 个点——决策模型没带来真增益，就别付 JEV 的钱和依赖，只做零成本的检索升级。
4. **维持 S0**：所有新系统比 S0 高 <5 个点——检索不是当前瓶颈，时间回到找真实商家试水。
5. **一票否决**：任何系统在 D/F 组出现编造（确认不存在的折扣码、声称已取消订单、把「洗碗机安全」说成「无铅认证」），该系统直接出局，不论总分。
6. **中文组单独判**：G 组若 S3 仍 <40%，说明 JEV 路线解决不了中文商家的问题，多语言要另找方案（这会影响商家定位：先做英文站点商家）。
